# Changelog

## 1.1.0
* Vibration on "+1" press (in addition to the sound), respecting the watch's vibration setting
* Reset by long-pressing the screen on touch watches without left buttons (venu3, vivoactive6) — with confirmation
* On such watches the hint changes to "hold screen = reset" and the left pointer arrow is hidden


## 1.0.0
* On-screen pointer markers: "+1" to the main button and "0" to the reset button
* First release: a simple tally counter
* "+1" via the main button (START/SELECT) or a screen tap, with a sound
* Reset to 0 by long-pressing the menu button (with confirmation)
* Current value is saved between launches
